👨‍💼 Admin Side

Web panel with session-based authentication for managing routes, landmarks, tickets, and settings

📱 User Side

Flutter mobile app with Sanctum token auth for route finding, fare calculation, and support

🔧 Shared Backend

Single Laravel 12 backend serves both web (admin) and API (mobile) routes

💾 Single Database

MySQL database storing all system data — changes by admin are instantly available to users

🔐 Admin Authentication

  • Session-based auth with cookies
  • Laravel web guard
  • Only role = 'admin' can access
  • CSRF protection enabled
  • Login throttling (5 attempts/min)
  • Activity logging for audit trail

📱 Mobile Authentication

  • Token-based auth with Laravel Sanctum
  • Personal Access Tokens
  • 30-day token expiry
  • Only role = 'user' can login
  • Rate limit: 60 req/min
  • Secure token storage on device

🛡️ API Security

  • Rate limiting (60 req/min per IP)
  • Bearer token authentication
  • Input validation & sanitization
  • CORS protection
  • SQL injection prevention (Eloquent ORM)
  • Passwords hashed with bcrypt

🔄 Data Synchronization

  • Tickets poll every 30 seconds
  • Routes refresh on app launch
  • Landmarks cached locally
  • Settings fetched before fare calc
  • Offline browsing of cached data
  • Queued submissions when offline
